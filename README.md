# 🌙 Lunar Moon

> ✨ **A little cosmic calm for every line of code.**

## 🌌 About the Theme

**Lunar Moon** is a dark Visual Studio Code theme inspired by the quiet beauty of a moonlit night. Deep plum backgrounds and muted violet surfaces create a cozy, focused workspace, while cherry-pink accents, moonlight cyan, soft lavender, mint green, and warm peach bring your code to life. 🌸

Designed to balance atmosphere with readability, Lunar Moon gives your editor a consistent look—from syntax highlighting to the interface surrounding your code. Whether you're learning something new, building a project, or debugging late into the night, let Lunar Moon keep your workspace calm, colorful, and unmistakably yours. 🌠

## 🎨 The Color Palette

- 🌑 **Midnight Plum** — deep, subdued backgrounds that set the scene.
- 🍇 **Muted Violet** — layered surfaces, selections, and subtle depth.
- 🩵 **Moonlight Cyan** — crisp highlights for functions and details.
- 🌸 **Cherry Pink** — expressive keywords and interactive accents.
- 🪻 **Soft Lavender** — gentle contrast for types and supporting syntax.
- 🍃 **Mint Green** — fresh color for strings and successful changes.
- 🍑 **Warm Peach** — a soft glow for numbers, warnings, and details.

## 💻 Made for Your Coding Space

Lunar Moon carries its cosmic palette throughout the **editor, sidebar, tabs, terminal, panels, selections, bracket guides, and Git decorations**—so your workspace feels cohesive from top to bottom.

## ✨ The Lunar Mood

Calm, dreamy, and colorful without losing sight of the code. 🌙⭐

## ✧ INSTALL 

1. Open the **Extensions** view (`Ctrl+Shift+X`, or `Cmd+Shift+X` on macOS).
2. Search for **Lunar Moon**.
3. Hit **Install**.

Or jump straight in from the terminal:

```bash
code --install-extension zso-Rose.lunar-moon
```

## ✧ ACTIVATE 

1. Open the Command Palette (`Ctrl+Shift+P`, or `Cmd+Shift+P` on macOS).
2. Run **Preferences: Color Theme** (`Ctrl+K Ctrl+T`, or `Cmd+K Cmd+T` on macOS).
3. Pick **Lunar Moon**, **Lunar Moon Bright** or **Lunar Moon Warm**.

Prefer `settings.json`?

```jsonc
{
  "workbench.colorTheme": "Lunar Moon" // or "Lunar Moon Bright" / "Lunar Moon Warm"
}
```
