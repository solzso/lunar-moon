# Lunar Moon

A moonlit dark theme for Visual Studio Code, in three variants: **Lunar Moon**, **Lunar Moon Bright** and **Lunar Moon Warm**.

Deep indigo backgrounds with rose keywords, aqua functions, mint strings and lavender types.

## Variants

| Theme | What's different |
| --- | --- |
| **Lunar Moon** | The base theme. Indigo editor (`#1E1C31`) with a near-black violet sidebar, activity bar, title bar and status bar (`#140D1F`). |
| **Lunar Moon Bright** | Same editor colors as Lunar Moon, with a lighter violet sidebar, activity bar, title bar, status bar and tab strip for a softer, lower-contrast layout. |
| **Lunar Moon Warm** | A plum-tinted editor, panel and terminal (`#231A2D`) and orchid class and type names. |

## Installation

1. Open the Extensions view (`Ctrl+Shift+X`, or `Cmd+Shift+X` on macOS).
2. Search for **Lunar Moon**.
3. Select **Install**.

Or install it from the command line:

```
code --install-extension zso-Rose.lunar-moon
```

## Activate a theme

1. Open the Command Palette (`Ctrl+Shift+P`, or `Cmd+Shift+P` on macOS).
2. Run **Preferences: Color Theme** (shortcut: `Ctrl+K Ctrl+T`, or `Cmd+K Cmd+T` on macOS).
3. Choose **Lunar Moon**, **Lunar Moon Bright** or **Lunar Moon Warm**.
